API reference

Automate the agreement on every file: when your case or practice management system opens a file, call FileSign and the client receives the agreement to sign. Authenticate with your workspace API key (Settings → Integrations).

Authentication

Authorization: Bearer fs_live_…

All requests and responses are JSON unless noted. Errors return {"error": "message"} with a 4xx/5xx status.

POST /api/files

Open a file and send the agreement. Uses the workspace's default agreement unless template_id is given.

{
  "client_name": "Jordan Example",          // required
  "client_email": "jordan@example.com",     // required
  "ref": "F-1001",                          // your file/case number (auto-generated if omitted)
  "template_id": "tpl_…",                   // optional
  "values": { "Policy Number": "P-123" },   // custom fields, keyed by field label or id
  "message": "Please sign so we can start.",// optional, shown to the client
  "send_email": true                        // email the client (if email is configured)
}

Response includes id, status and signing_url, which you can embed in your own portal, SMS or email.

POST /api/files/bulk

{ "template_id": "tpl_…", "send_email": true, "files": [ { "client_name": "…", "client_email": "…", "ref": "…" } ] }

GET /api/files · GET /api/files/:id

List files (filters: status = pending | completed | declined | expired | voided, q = search) or get one with its full audit trail.

GET /api/files/:id/document.pdf

The signed PDF (with certificate of completion) once completed, otherwise the document as sent.

POST /api/files/:id/remind · POST /api/files/:id/void

GET /api/templates · POST /api/templates

Upload an agreement as raw bytes (Content-Type: application/pdf, ?filename=agreement.pdf) or JSON {"filename","name","content_base64"}. Fields are detected automatically; review them in the app before sending.

Webhooks

Set a webhook URL in Settings. FileSign POSTs events: file.sent, file.viewed, file.completed, file.declined, file.voided.

POST https://your-system.example.com/filesign
X-FileSign-Event: file.completed
X-FileSign-Signature: sha256=<HMAC-SHA256 of raw body with your webhook secret>

{ "event": "file.completed", "created_at": "…", "file": { "id": "file_…", "ref": "F-1001", "status": "completed", … } }
